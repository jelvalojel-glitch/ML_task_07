# ML_task_07

В ходе практической работы была построена модель случайного леса и проведено сравнение с одиночным деревом решений. Для подбора гиперпараметров `n_estimators`, `max_depth` и `min_samples_leaf` использовался перебор значений с пятикратной кросс-валидацией.

Сначала были сравнены дерево решений и случайный лес с параметрами по умолчанию. Затем была выбрана модель с лучшими гиперпараметрами. Сравнение показало, что результат остался прежним.

Для анализа важности признаков использовался метод permutation importance. В результате наиболее значимыми оказались age work_type smoking_status, а наименее значимыми — avg_glucose_level heart_disease bmi.

В эксперименте по удалению признаков было установлено, что после исключения наименее важных признаков качество немного ухудшилось. Следовательно, признаки heart_disease	bmi можно рассматривать как кандидатов на исключение, если сокращение числа признаков оправдано и результат подтверждается на отдельной проверочной выборке.

Таким образом, случайный лес позволяет оценить вклад признаков и сравнить качество ансамблевой модели с одиночным деревом решений. Окончательный выбор модели должен учитывать как качество предсказаний, так и сложность модели.
